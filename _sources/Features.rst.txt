Features
===============
qvasp is a high-throughput material design software based on Fotran and Bash programming language with the aim of setting up, steering, and analyzing first principle simulations. The qvasp has been constructed with a number of “design goals” that make it:

* **Easy to use**:
   qvasp provides a command-line help document: **qvasp -help** prints the full command table, and every command prints what it did and which files it wrote. qvasp can fastly prepare the input files for first principle simulations, and provide effective toolkit to postprocessing the raw data of first principle simulations.
 
* **Flexible**:
   qvasp provide the source codes in the packages, therefore, the users can modified the raw code to match their calculated systems.
 
* **Customizable**:
   qvasp provides an interface for users to add their own tools, such as `vaspkit <https://vaspkit.com/>`_: put the executable in ``USERDefine/TooLs/`` and "**qvasp -vaspkit**" calls it. The users can also packaging their customized qvasp code using "tar -zcPvf qvasp-vxx", and install it on other Linux system.

qvasp -findcell        Finding the primitive cell (spglib)
qvasp -defect          Finding inequivalent defect/doping sites
qvasp -neb             Aligning endpoints for NEB calculation and interpolation
====================== ==================================================================

.. note::
   **qvasp -freqfix** (formerly **-zc**) is used to remove imaginary frequencies. Mode 1
   (molecule or Gamma point) displaces the atoms along the soft-mode eigenvector printed by
   VASP by a physical amplitude in Angstrom (default 0.10 A); mode 2 (solid) applies an
   acoustic-sum-rule correction to FORCE_CONSTANTS.
   **qvasp -c2p** reads both the plain CIF symmetry tags and the Materials Studio ones, so the
   separate **-c2p2** command of v2.x is no longer needed.
   **qvasp -neb reads two endpoint POSCARs, aligns the atoms by pairing nearest-neighbour sites, and produces the interpolated POSCARs 01-05 (default)**.
   **qvasp -sqs** builds a special quasirandom structure by pair-correlation matching, the
   ATAT/mcsqs approach, without needing ATAT.

Post: magnetic / optical
^^^^^^^^^^^^^^^^^^^^^^^^^
==================== ==============================================================
   Command                         Function
==================== ==============================================================
qvasp -magm          Magnetic suite: spin density / J / Tc / MAE / MAGMOM (see below)
qvasp -opticsd       Obtaining absorption spectrum (3D/2D) from LOPTICS data
qvasp -ir            IR spectrum from Gamma phonons + Born effective charges (DFPT)
qvasp -raman         Raman spectrum via d(epsilon)/dQ (two-stage LOPTICS workflow)
==================== ==============================================================

.. note::
   **qvasp -magm menu**: 1) spinden: spin density & magnetic moment from CHGCAR;
   2) magconf: generate FM/AFM/FIM magnetic configurations (run-length MAGMOM);
   3) fitj: extract exchange parameters J_n by mapping total energies onto the
   Heisenberg model E = E0 - sum J_n*C_n; 4) curie: Curie/Neel temperature via
   Monte Carlo (classical Heisenberg) and mean-field estimation; 5) mae:
   magnetocrystalline anisotropy energy from spin-orbit runs along x/y/z;
   6) maginit: initialize MAGMOM from the OUTCAR magnetization table.

Post: thermo / lattice
^^^^^^^^^^^^^^^^^^^^^^^^^
==================== ==============================================================
   Command                         Function
==================== ==============================================================
qvasp -phonond       Obtaining phonon data from OUTCAR
qvasp -elasticd      Obtaining elastic constants in mechanical calculation
qvasp -thermo        Thermal corrections H/S/G(T) from frequency calculation
qvasp -teprop        Thermoelectric coefficients S/sigma/kappa/ZT (Boltzmann transport)
qvasp -e             Printing energy of enthalpy from OUTCAR
qvasp -eos           EOS fit: B0/V0 from E-V data (Birch-Murnaghan)
qvasp -zpe           Obtaining the zero point energy from frequency calculation
==================== ==============================================================

.. note::
   **qvasp -teprop** solves the linearized Boltzmann transport equation in the
   constant-relaxation-time approximation, using a real-space Fourier
   interpolation of the band energies.  It reads EIGENVAL, POSCAR and OUTCAR,
   asks for the relaxation time, the temperature and doping ranges, and writes
   ``thermo.dat`` with the Seebeck coefficient, the electrical and lattice
   thermal conductivity, the power factor and ZT.  A converged dense k-mesh is
   required; see :doc:`Tutorials`.

Post: charge / WF
^^^^^^^^^^^^^^^^^^^^^
==================== ==============================================================
   Command                         Function
==================== ==============================================================
qvasp -baderd        Bader charges (built-in Henkelman bader wrapper)
qvasp -dband         d-band center from DOSCAR
qvasp -wkd           Obtaining work function and electrostatic potential (vline.dat)
qvasp -chgdif        Charge density difference of CHGCARs
qvasp -wfn           Converting WAVECAR into real/imaginary wavefunction files
==================== ==============================================================

.. note::
   **qvasp -baderd requires LAECHG = .TRUE. (AECCAR0/AECCAR2). It builds CHGCAR_sum
   internally, locates the external "bader" executable (./bader, qvasp root or PATH),
   runs "bader CHGCAR -ref CHGCAR_sum", parses ACF.dat, and prints the per-atom
   Bader charges combined with the POTCAR ZVAL valences (bader_charges.dat)**.
   **qvasp -wfn** writes ``WFN_REAL_B####_K####.vasp`` and
   ``WFN_IMAG_B####_K####.vasp`` for one band and one k-point, plus
   ``WFN_INFO.dat``; the files are ordinary VASP CHGCAR-style grids, so they can
   be opened in VESTA to plot an orbital.

Surfaces
^^^^^^^^^^^^^^^^^^^^^
==================== ==============================================================
   Command                         Function
==================== ==============================================================
qvasp -esurf         Surface energy from slab calculations with 1/N extrapolation
==================== ==============================================================

.. note::
   **qvasp -esurf reads a bulk reference folder (mu_bulk = E_bulk/N_bulk) and several
   slab folders; gamma = (E_slab - N*mu_bulk)/(2A). Giving the layer number N of each
   slab additionally yields a linear fit of gamma vs 1/N whose intercept is the
   extrapolated surface energy of the bulk-truncated surface (esurf.dat)**.
