Release Notes
========================

Version 3.01 (2026.11.23)
----------------------------
This release is the outcome of an independent pre-release test: every one of the
89 examples was rebuilt with VASP 6.5.1, replayed byte by byte, and every
physical number was recomputed with ASE / spglib / phonopy / numpy before the
program was accepted.

 * 2026.11.23 Add **qvasp -freqfix** (the old ``-zc`` name still works).  Mode 1
   (molecule / Gamma point) de-mass-weights the soft-mode eigenvector printed by
   VASP, normalises it and displaces the atoms by a **physical amplitude**
   (default 0.10 A, not a dimensionless factor); mode 2 (solid) applies an
   acoustic-sum-rule correction to ``FORCE_CONSTANTS``.  Verified on methanol
   (the -182 cm-1 mode removed), SrTiO3 (-148.8 -> +108.6 cm-1), diamond,
   MgSiO3 and CN3 (ASR drift reduced to 1e-15).
 * 2026.11.23 Fix **POSCAR reading**, the most far-reaching defect of this
   round: the coordinate-mode line ``Cartesian`` contains an upper-case ``S``,
   so the test ``INDEX(upper(line),'S') > 0`` mistook it for ``Selective
   dynamics`` and consumed one extra line.  Without a trailing blank line this
   aborted with ``end-of-file during read``; with one it silently dropped the
   first atom (a 5-atom SrTiO3 cell became 4 atoms after ``-sc 1 1 1``).  The
   test now checks the first character only.  Affected ``-sc``, ``-k``,
   ``-kline``, ``-khse``, ``-kphonon``, ``-freqfix``, ``-magconf``, ``-fitj``,
   ``-curie``, ``-findcell``, ``-findsym``, ``-kpath``, ``-esurf``, ``-raman``
   and ``-elasticd``.
 * 2026.11.23 Fix **qvasp -opticsd**: ``vasprun.xml`` may contain two
   ``<dielectricfunction>`` blocks (``comment="density-density"`` and
   ``comment="current-current"``).  The old parser concatenated both, which
   produced a duplicated, non-monotonic energy axis, and the REAL block
   overwrote the IMAG rows because both used one work array.  Only the
   density-density block is kept now and IMAG/REAL use separate arrays;
   ``IMAG.dat``/``REAL.dat`` match vasprun.xml exactly (2000 rows, 0-39.09 eV).
 * 2026.11.23 Fix **qvasp -ldos**: the argument list was read one position late
   (``qgetarg(2)`` with ``nfiles = argc-1``), so ``qvasp -ldos 2 3`` returned a
   single atom's DOS instead of the sum.  Arguments are now ``qgetarg(1..argc)``
   and the summation core accumulates every listed file; ``LDOS.dat`` equals
   ``DOS2.dat + DOS3.dat`` to machine precision.
 * 2026.11.23 Fix **qvasp -mos**: layer 2 was placed by a rotation plus a scalar
   isotropic strain and then wrapped onto the layer-1 supercell, which sheared a
   rectangular lattice into nine different P-P bond lengths (1.905-2.439 A).
   The mapping is now the exact affine transform ``W = inv(T2)*T1`` (twist and
   anisotropic strain included); the principal strains are printed and a warning
   is issued when their magnitude exceeds 3 %.
 * 2026.11.23 Fix **qvasp -mae**: the OUTCAR ``magnetization (x)`` table was
   parsed with a fixed two-line skip, so the dashed separator line was taken as
   the first atom and MAGMOM was written as ``********`` (the log even printed
   ``max|m| = -4491890268339332710``).  The reader now skips blank, header and
   separator lines until the first all-numeric ion row (``max|m| = 1.661 muB``
   on the hcp Co example).
 * 2026.11.23 Rewrite **-mde** and **-mdm** in pure Fortran, so the whole MD
   toolkit runs without python.
 * 2026.11.23 **Gaussian broadening is the default** in ``-ir`` and ``-raman``
   (answer ``L`` for Lorentzian).  A Lorentzian tail decays only as
   1/Delta^2 and leaves a visible shoulder tens of cm-1 away from a strong mode,
   which is mathematically correct but easy to mistake for a second peak.
 * 2026.11.23 Rebuild all 89 examples with VASP 6.5.1 and re-test them.  The
   ``-kline`` / ``-khse`` / ``-kphonon`` examples used a 2-atom simple-cubic
   cell labelled "diamond" (spglib R-3m, 166), so the generated path was not the
   fcc path; they now use the true diamond primitive cell (a = 3.567 A, fcc
   vectors, 2 C atoms; spglib 227 Fd-3m) and produce the standard path
   G-X-W-K-G-L-U-W-L-K, U-X.  The ``-ir`` example was the eclipsed methanol
   conformer (a spurious -304 cm-1 mode) and is now the staggered one.  The
   ``-zc`` example was refreshed for the three-step ``-freqfix`` dialogue.
 * 2026.11.23 Document that ``qvasp -thermo`` clamps frequencies below
   50 cm-1 only for the entropy, while ZPE and H use the raw frequencies (for
   the surface example S would be 86.56 instead of 40.31 J/mol/K if the clamp
   were not applied, and G would differ by 0.14 eV).
 * 2026.11.23 Unify the version string to v3.01 in ``Makefile``,
   ``install.sh``, the ``qvasp.f90`` banner and the help table; regroup the help
   output and fix the "Devoloper Info" spelling.

Version 3.0 (2026.10.27)
----------------------------
 * 2026.10.27 Add the magnetic suite **qvasp -magm** with six sub-functions:
   1) spinden (spin density and magnetic moment from CHGCAR);
   2) magconf (generate FM/AFM/FIM magnetic configurations, run-length MAGMOM);
   3) fitj (extract exchange parameters J_n from total energies by mapping on the
   Heisenberg model E = E0 - sum J_n*C_n, J_table.dat);
   4) curie (Curie/Neel temperature via classical Heisenberg Monte Carlo plus
   mean-field estimation);
   5) mae (magnetocrystalline anisotropy energy from spin-orbit calculations);
   6) maginit (initialize MAGMOM from the OUTCAR magnetization table).
 * 2026.10.27 Rewrite qvasp -baderd as a built-in wrapper of the Henkelman bader
   code: builds CHGCAR_sum = AECCAR0 + AECCAR2 internally, locates the bader
   executable, parses ACF.dat and combines with POTCAR ZVAL valences
   (bader_charges.dat).
 * 2026.10.27 Add qvasp -esurf: surface energy from slab calculations,
   gamma = (E_slab - N*mu_bulk)/(2A), with optional 1/N extrapolation.
 * 2026.10.27 Add qvasp -ir: infrared spectrum from Gamma-point phonons and Born
   effective charges (DFPT, IBRION=5..8 + LEPSILON), with Lorentzian broadening.
 * 2026.10.27 Add qvasp -raman: Raman spectrum via d(epsilon)/dQ with a two-stage
   workflow (gen: displaced LOPTICS runs for every mode; get: activities
   S = 45*abar^2 + 7*gamma^2 and depolarization ratio).
 * 2026.10.27 Add qvasp -effmass: carrier effective mass from a parabolic fit of
   the band structure along a KPOINTS path (electron at CBM / hole at VBM).
 * 2026.10.27 Add qvasp -defect: inequivalent defect/doping sites of POSCAR.
 * 2026.10.27 Add qvasp -neb: align endpoints for NEB and interpolate images.
 * 2026.10.27 Add qvasp -khse: KPOINTS for HSE06 band calculations;
   add qvasp -kphonon: KPOINTS for phonon spectrum calculations.
 * 2026.10.27 Add qvasp -thermo: thermal corrections H/S/G(T) from frequency
   calculations; add qvasp -dband: d-band center from DOSCAR;
   add qvasp -msd: MSD & diffusion for MD; add qvasp -rdf: RDF g(r)/CN(r) for MD.
 * 2026.10.27 Extend qvasp -opticsd to support the 2D absorption spectrum.
 * 2026.10.27 Add qvasp -banduf: band unfolding (EBS) of supercell calculations;
   add qvasp -bandp: projected band structure.
 * 2026.10.27 Regroup "qvasp -help" into INCAR / POSCAR structure / KPOINTS /
   POTCAR / Post: band-DOS / magnetic-optical / thermo-lattice / charge-WF /
   MD-misc / Surfaces / Jobs-misc categories; remove the job submission entries
   (-sub, -d) from the help document.
 * 2026.10.27 Extend the Examples folder: sw, orthcell, redlat, as, clean, khse,
   3dkpoints, magm (g-C4N3, Phys. Rev. Lett. 108, 197207) and others.
 * 2026.10.27 Numerous bug fixes: directory probing (INQUIRE) on Intel Fortran,
   exchange-parameter least-squares solver, MAGMOM string accumulation in
   maginit/magconf/mae, ACF.dat CHARGE column parsing, Raman dielectric-tensor
   parsing (XML tag robustness), effective-mass KPOINTS recognition (standard
   explicit list and standard line-mode), and more.
 * 2026.11.05 Pre-release QA (validated on real g-C4N3 data, cross-checked
   against VASPKIT 1.12). qvasp -banduf EBS verified against VASPKIT task 282
   on the same supercell run: 563/563 significant-weight levels agree within
   0.0001 eV; the example EBS.dat is reproduced bit-for-bit.
 * 2026.11.05 qvasp -dosd total DOS verified against VASPKIT task 111 (exact
   match); qvasp -bandd verified against the raw EIGENVAL (all levels exact).
 * 2026.11.05 den2vasp (bundled CASTEP tool) unit-conversion bug fixed at
   source: the .den_fmt lattice (bohr) was divided by 0.529177 (wrong
   direction, lattice off by 3.568x) and the density (e/bohr^3) was written
   without conversion to e/A^3 (factor 6.7483 missing); regression-tested
   with a synthetic .castep/.den_fmt pair.
 * 2026.11.05 EOF hardening: interactive prompts across ~25 tools (bandd,
   3dband, msd, dband, rdf, curie, fitj, magconf, esurf, raman, defect, neb,
   cls, sw, fix, c2p, nanotube, 3dkpoints, ...) no longer abort with a
   Fortran runtime error when stdin is closed (batch mode); EOF now behaves
   like an empty input and tool defaults apply.
 * 2026.11.05 qvasp -banduf warns explicitly when OUTCAR is missing instead
   of silently shifting the EBS by Fermi = 0.
