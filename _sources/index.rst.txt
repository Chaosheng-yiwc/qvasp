Overview
===================================
qvasp aims at providing a powerful and user-friendly interface to perform high throughput analysis of various material properties from the raw calculated data using the widely-used VASP code. The program can also construct various materials models. 

.. code-block:: none

    > qvasp -help
    +=================================================================================================+
    |                              qvasp usage v3.01  (Author: Wencai Yi)                             |
    |                      magnetic suite / optics / surfaces / freqfix  2026-11-23                   |
    +=============== INCAR templates ================+=============== INCAR templates ================+
    | qvasp -relax  For structure optimization cal.  | qvasp -md  For molecular dynamics cal.         |
    | qvasp -scf  For self-consistent cal.           | qvasp -elastic  For elastic constants cal.     |
    | qvasp -band  For energy band cal.              | qvasp -partchg  For partial charge cal.        |
    | qvasp -dos  For density of states cal.         | qvasp -freq  For frequency cal.                |
    | qvasp -elf  For ELF cal.                       | qvasp -optics  For optical property cal.       |
    | qvasp -wk  For work function cal.              | qvasp -phonon  For phonon spectrum cal.        |
    | qvasp -bader  For Bader charge cal.            | qvasp -ts  For transition state cal.           |
    | qvasp -hse  For HSE06 cal.                     | qvasp -lobster  For LOBSTER cal.               |
    +=============== POSCAR structure ===============+=========== POSCAR structure (cont.) ===========+
    | qvasp -fix  Fix atomic layer for POSCAR        | qvasp -sw POS1  Switch (a,b,c) axis of POS1    |
    | qvasp -it  Insert points for TS cal.(method1)  | qvasp -orthcell POS1  Construct orthogonal cell|
    | qvasp -itms  Insert points for TS cal.(method2)| qvasp -redlat POS1  Redefine lattice setting   |
    | qvasp -sc  Create supercell for POSCAR         | qvasp -cls POSCAR  Cleaving surface            |
    | qvasp -freqfix  Imaginary frequency fix        | qvasp -nanotube POS1  Roll nanosheet           |
    | qvasp -c2p  Transfer cif file to POSCAR        | qvasp -hej POS1 POS2  Construct heterojunction |
    | qvasp -sqs POS1  Build SQS for HEA / oxides    | qvasp -mos POS1 POS2  Construct Moire superlat |
    | qvasp -p2c  Transfer POSCAR to *.cif           | qvasp -as POS1  Analysis adsorption sites      |
    | qvasp -findsym  Find the symmetry              +==================== POTCAR ====================+
    | qvasp -findcell  Find the primitive cell       | qvasp -pw91 ELE  Produce POTCAR from PAW_PW91  |
    | qvasp -defect  Inequivalent defect sites       | qvasp -pbe ELE  Produce POTCAR from PAW_PBE    |
    | qvasp -neb  Align endpoints for NEB            | qvasp -lda ELE  Produce POTCAR from PAW_LDA    |
    +=================== KPOINTS ====================+ qvasp -cp  Check the POTCAR                    |
    | qvasp -k density  Create KPOINTS (Auto mesh)   +=========== Post: magnetic / optical ===========+
    | qvasp -3k density  Create KPOINTS:3D materials | qvasp -opticsd  Get optical data (3D/2D)       |
    | qvasp -kline  Create KPOINTS (Line mode)       | qvasp -ir  IR spectrum (Born charges)          |
    | qvasp -khse  Create KPOINTS for HSE06          | qvasp -raman  Raman spectrum (d(eps)/dQ)       |
    | qvasp -kphonon  KPOINTS for phonon spectrum    | qvasp -magm  Magnetic suite: spin/J/Tc/MAE     |
    | qvasp -3dkpoints  Create KPOINTS for 3D band   +============ Post: thermo / lattice ============+
    +=============== Post: band / DOS ===============+ qvasp -phonond  Obtain phonon data             |
    | qvasp -bandd  Obtain band data                 | qvasp -elasticd  Obtain elastic constants      |
    | qvasp -dosd  Obtain DOS data                   | qvasp -thermo  Thermal corrections H/S/G(T)    |
    | qvasp -ldos 1 2  Obtain LDOS data              | qvasp -teprop  Thermoelectric S/sigma/kappa/ZT |
    | qvasp -bandp  Projected band data              | qvasp -e  Read energy from OUTCAR              |
    | qvasp -banduf  Band unfolding (EBS)            | qvasp -eos  EOS fit: B0/V0 from E-V data       |
    | qvasp -3dband  Obtain 3D band for 2D materials | qvasp -zpe  Obtain ZPE value                   |
    | qvasp -scissorb  Corrected band via scissor    +=========== Post: MD analysis / misc ===========+
    | qvasp -scissord  Corrected DOS via scissor     | qvasp -msd  MSD & diffusion for MD             |
    | qvasp -effmass  Carrier effective mass (fit)   | qvasp -rdf  Obtain RDF g(r)/CN(r) for MD       |

    | qvasp -baderd  Bader charges (Henkelman code)  | qvasp -gauss  Transfer OUTCAR to Gauss.log     |
    | qvasp -dband  d-band center from DOSCAR        | qvasp -mde  Obtain Energy data for MD          |

    | qvasp -atomkit                    Call atomkit, ref:https://vaspkit.com/atomkit.html            |

    | qvasp -den2vasp                   Transfer density file (CASTEP) to CHGCAR (VASP)               |
    | qvasp -res2vasp                   Transfer res format to POSCAR(Chaoyu He)                      |
    | qvasp -ueff                       Fitting the value of U for LDA+U method (linear response)     |
    | qvasp -piez                       Calculate the piezoelectric properties                        |
    +======================================== Developer Info =========================================+
    | Cite: [1] W.Yi,G.Tang, et al. qvasp:A Flexible Toolkit for VASP Users in Materials Simulations, |
    | Comput. Phys. Commun., 2020, 257, 107535, online document: https://qvasp.com/                   |
    +=================================================================================================+

The program is a single executable: every command listed above is built in, and no python or external script is needed any more.
